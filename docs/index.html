ESP32 · Waveshare LCD

Una matriz de LEDs en tu pantallaAn LED matrix on your screen

Convierte una placa ESP32 con LCD en una matriz de LEDs RGB o monocolor. Muestra texto, efectos, dibujos y animaciones, y tiene un líquido que obedece al acelerómetro. Se controla desde su web, por HTTP o desde una IA vía MCP. Turn an ESP32 board with an LCD into an RGB or single-color LED matrix. It shows text, effects, drawings and animations, plus a liquid that follows the accelerometer. Control it from its web UI, over HTTP or from an AI through MCP.

FirmwareFirmware

Sketch Arduino (core esp32 3.2.0). La matriz virtual vive en RAM y se pinta por diferencias sobre un canvas de Arduino_GFX que cubre toda la pantalla.Arduino sketch (esp32 core 3.2.0). The virtual matrix lives in RAM and is diff-rendered onto an Arduino_GFX canvas that covers the whole screen.

EscenasScenes

Todo es una escena JSON (text, effect, pixels, anim) que se guarda en NVS y sobrevive a un reinicio.Everything is a JSON scene (text, effect, pixels, anim) persisted in NVS so it survives a reboot.
